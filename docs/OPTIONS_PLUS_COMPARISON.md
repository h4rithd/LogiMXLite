# Options+ comparison and limits

Inspected 2026-10-20 against the installed Logitech Options+ 2.9.994631 application, its local agent, and owner-supplied screenshots. This comparison covers the MX Master 3S and MX Mechanical Mini for Mac. Flow is outside the requested scope. Private source configuration files are not included in this repository or app bundle.

REA inventoried the Electron `app.asar` (580 entries, evidence `ev_e253ed5dc026c82b144ee3c3accf1d89d3fe475d1c4a42c8690fe5f780a01aed`) and analyzed `main.js` (509 modules, evidence `ev_355e8132859461bf32ba390aeb5918c2b803a19b89edb9a20ba22280524af176`). The full JavaScript analyzer stopped with a provider `unknown_budget` error; its partial result is `ev_8fbeb79701def7ab237c6ef4f9887fa333d0d621d703823b36569d6b5743cc11`. The native agent was inspected by symbol and focused disassembly because full binary indexing did not complete.

The agent's `ButtonGesture4wayState` functions calculate start and action thresholds as `50 × (1 − sensitivity)` and `250 × (1 − sensitivity)`. At sensitivity zero, LogiMXLite uses 50 and 250 raw units. `GestureTriggerBaseState::AngleSnapping` accepts a movement sample on an axis only when that axis is at least twice the other; near-diagonal samples contribute to neither axis. LogiMXLite now uses that rule. Device events are queued on the main dispatch queue in HID arrival order, and held gestures are canceled when secure input or Accessibility stops action delivery. A lost thumb-button release is canceled after eight seconds. Saving settings no longer forces every mapped control through a restore-and-redivert cycle. The 0.4-second repeat pause remains an implementation value; exact Options+ pause settings and end-to-end latency need a controlled device comparison.

The installed Options+ UI is Electron; its package contains hundreds of hashed WebP/SVG illustrations, JavaScript bundles and videos. A read-only ASAR inventory/contact sheet found tutorial illustrations but not the clean white mouse/keyboard product cutouts visible in the screenshots. LogiMXLite uses generated transparent renderings derived from the owner's screenshots instead of bundling extracted Options+ assets. Its UI reproduces the dark dashboard, turquoise selection, battery chips, large device imagery, navigation and action panels.

LogiMXLite uses the macOS IOHID FF43:0202 vendor collection to talk to the two specified BLE devices. Its read-only diagnosis enumerated both feature tables and showed battery, DPI and keyboard state. Some Options+ settings values are normalized numbers, while hardware DPI uses a discrete device range. No verified formula maps Options+ pointer-speed or wheel-speed percentages to identical macOS/device behavior. The importer preserves observations and translates only supported settings; exact pointer acceleration and scroll feel remain a physical comparison task. The UI now shows the imported slider positions (60% vertical and 84% thumb-wheel in the supplied reference) rather than its internal event multipliers. Adjustments preview live, and the vertical slider was returned from a saved 100% setting to approximately the source 60% position on this Mac.

| Easy-Switch | Three channels shown read-only; device button performs switching | Active slot and host names are not verified by current readback |

Options+ has actions whose exact behavior is not established from the supplied reference or local static inspection. Pointer-speed toggling, proprietary Word/PowerPoint zoom, arbitrary folder opening and unknown source macros stay marked **Requires confirmation** instead of executing a guessed substitute. Native horizontal thumb scrolling remains available. The UI does not claim cloud account, pairing inside the app, or Flow.

The Options+ agent can conflict with LogiMXLite button diversion when it is running. A matching UI and passing unit tests cannot establish equal HID timing or physical smoothness. Hardware acceptance should be performed with Options+ fully quit, using the checklist in [HARDWARE_MATRIX.md](HARDWARE_MATRIX.md). Long-duration CPU, memory and energy measurements remain open.
